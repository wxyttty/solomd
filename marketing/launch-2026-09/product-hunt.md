## Description (≤ 260)

```
Write Markdown the way it looks: markers fade as you type. Math, Mermaid
diagrams, whiteboards, wiki links, and export to PDF, Word and HTML. On
Windows, macOS, Linux, iOS and Android. MIT-licensed, no account, and an MCP
server for your AI tools.
```

## First comment (maker)

```
Hi Product Hunt! I built SoloMD because I wanted Typora's editing feel in
something open source that also runs on my phone.

What's in it:
• Live preview: Markdown markers hide when the cursor leaves the line
• KaTeX, Mermaid/PlantUML, tldraw whiteboards
• Wiki links, backlinks, graph. Your notes stay plain .md files in a folder
• Export to PDF, Word and standalone HTML
• Bundled MCP server, so Claude, Cursor and other agents can read your notes
  (write access only if you turn it on)

A confession: most of SoloMD is written and released by Claude Code, with me
reviewing and deciding what ships. It's all MIT on GitHub if you want to
look.

I'd love to hear what would make you switch from your current editor.
```
