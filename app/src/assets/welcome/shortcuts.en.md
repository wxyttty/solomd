# Shortcuts

`Ctrl` on Linux / Windows = `Cmd` on Mac. Everything else listed here is the same.

## Files

| | |
| --- | --- |
| `Ctrl+N` | New markdown file |
| `Ctrl+Alt+N` | New plain text file |
| `Ctrl+Shift+N` | New window |
| `Ctrl+O` | Open file… |
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save As… |
| `Ctrl+W` | Close tab |

## View

| | |
| --- | --- |
| `Ctrl+Shift+P` | Cycle Edit / Split / Preview |
| `Ctrl+B` | Toggle file tree |
| `Ctrl+Shift+O` | Toggle outline |
| `Ctrl+\` | Split editor right |
| `Ctrl+Shift+\` | Split editor down |
| `Ctrl+Alt+→ / ←` | Focus next / previous pane |

## Formatting

Press once on a selection to apply, again to remove. With nothing selected it acts on the word under the cursor.

| | |
| --- | --- |
| `Ctrl+Shift+B` | Bold (want `Ctrl+B`? see the tips below) |
| `Ctrl+I` | Italic |
| `Ctrl+Shift+X` | Strikethrough |
| `Ctrl+Shift+M` | Inline code |
| `Ctrl+K` | Link |
| `Ctrl+1` … `Ctrl+6` | Heading 1–6 |
| `Ctrl+Alt+Q` | Blockquote |
| `Ctrl+Alt+7` / `8` / `9` | Numbered / bulleted / task list |
| `Ctrl+Alt+K` | Code block |

## Tips

- The command palette (`Ctrl+Shift+K`) lists **every** command, with current shortcuts. If you forget a binding, this is faster than this cheat sheet.
- Most settings live in `Ctrl+,`, including font size, telemetry opt-out, "open file in new window", and font family.
- **Every shortcut can be changed**: Settings → Shortcuts. Click *Change* on a row and press the new chord; a clash with another command is reported on the spot.
- Used to `Ctrl+B` for bold, as in Typora or Word? The *Writer preset* button at the top of Settings → Shortcuts swaps it in with one click (the file tree moves to `Ctrl+Shift+B`), and back again.
- This page lists the **defaults**. Once you have changed something, trust `F1` → Shortcuts instead — it reads your current bindings.
