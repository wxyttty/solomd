# ADR-0004：UI 全部中文硬编码，无 i18n 层

- 状态：已采纳（2026-08-26）
- 关联：`gpui/crates/app/src/` 全部面板

## 背景

原 Tauri 版是面向发布的多语言产品（README 十余种语言、Vue i18n 目录）。GPUI 迁移时需决定是否迁移 i18n 层。gpui-component 自带 rust-i18n 能力，迁移成本不为零但可控。

## 决策

全部用户可见字符串**中文硬编码**，不引入 i18n 层。

## 真实权衡

- **理由**：本仓库已转为自用 fork（见 ADR-0001 范围裁剪），唯一用户是中文母语者；i18n 层的维护成本（每个新功能 × N 语言）没有对应收益。
- **代价**：若未来要重新发布多语言版，需要全量提取字符串——但届时用工具扫描中文字符串即可，成本不会高于现在维护 i18n 表。
- **否决的替代方案**：rust-i18n 单语言表 = 多一层间接却只服务一种语言，纯开销。

## 后果

- 新 UI 代码直接写中文字符串；错误消息也中文化（core 对外 API `Result<T, String>` 约定的配套）。
- 旧 `app/src/i18n/` 仅作历史参照。
